# Product Inventory Management API

A hands-on FastAPI project built step by step while following a FastAPI tutorial.

## Learning goals

- Build REST API endpoints with FastAPI
- Validate request and response data with Pydantic
- Implement CRUD operations for products
- Connect the API to a database
- Integrate a frontend with the backend
- Practice Git and GitHub commits throughout development

## Run locally

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Open http://127.0.0.1:8000 and http://127.0.0.1:8000/docs.
